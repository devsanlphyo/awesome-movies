# awesome-movies

All your beloved movies are here. Go and check it out and enjoy.

Professional movies website built with ReactJS.

### Local Development

For local development, you should have installed NodeJs and Git bash on your machine.

```bash
git clone
cd awesome-movies
npm install
npm run dev
```
